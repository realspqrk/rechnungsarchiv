1. Current: Rechtsklick auf die Seite → „Ins Deutsche übersetzen“.

2. Current: Die Bestätigung kommt per E-Mail mit dem Betreff „Recarga realizada“ (Aufladung durchgeführt). Bis das Guthaben im Konto steht, kann es etwas dauern.
Proposed: Die Bestätigung kommt per E-Mail mit dem Betreff „RECARGA REALIZADA“ (Aufladung durchgeführt). Bis das Guthaben im Konto steht, können mehrere Stunden vergehen.
Reason: The real subject is all capitals, so a search must match it. The test took hours; „etwas dauern“ reads like a few minutes.
